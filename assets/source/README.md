# Fontes originais de arte

Os seis PNGs com nomes de ambientes são composições originais geradas para
IdleFarm 0.2.0, 1672×941 pixels. `birds.png`, `livestock.png` e `dogs.png` são
atlases transparentes 1536×1024, com quatro espécies e seis poses por espécie.
`crop-stages.png` contém cinco culturas e quatro estágios em 1122×1402.

As cópias originais foram mantidas sem alteração. A saída de runtime é preparada
por `../../tools/generate_art.py`, com parâmetros editáveis de escala, iluminação
e máscaras. Consulte `../ART_DIRECTION.md` para o processo e a direção visual.
Estas fontes não são incluídas no executável distribuído.
